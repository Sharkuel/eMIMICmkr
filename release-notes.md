The first release of eMIMICmkr: turn the drum kits in your VST plugins into instruments for the Pearl Mimic Pro.

## What it does

- **Hosts your drum VST3 plugins** and reads the kit you have loaded, naming each piece automatically. Kit reading works with Superior Drummer 3, BFD3, Addictive Drums 2, MODO DRUM, Ugritone, DW Soundworks and ML Drums.
- **Maps every piece for you** from the plugin's MIDI map, with built-in maps for several Kontakt libraries and the option to load your own.
- **Records every zone at many velocities**: kick, snare (center, rimshot, rimclick, side and more), toms with head and rim zones, hi-hats across every openness step, rides and crashes with bell, bow and edge.
- **Builds the Mimic .mci instruments for you**, sorting layers by velocity, adding round robins and fitting each piece inside the Mimic's limits. Cymbals ring out naturally and stay in stereo.
- **3-zone crashes** are built in the ride format so they appear in the Mimic's ride menu.
- **Builds a Mimic kit preset** so the whole kit loads in one go.
- **Converts existing WAV folders** too, if you already have recordings.
- **Help mode**: press Help and click any control to read what it does.

## Downloads

| System | File |
|---|---|
| Windows | `eMIMICmkr-Windows-x64-Setup.exe` (or the .zip) |
| macOS | `eMIMICmkr-macOS.dmg` (or the .zip) |
| Linux | AppImage, .deb, .rpm or the .tar.gz |

The installers aren't signed yet. On Windows, click **More info > Run anyway** when SmartScreen warns. On macOS, right-click the app and choose **Open** the first time.

## Missing your plugin?

Use **Save state** in the app and attach the file to a plugin request on GitHub, and we'll add support for it.
